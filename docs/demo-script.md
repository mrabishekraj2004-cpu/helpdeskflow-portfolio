# Three-minute demonstration

Prepare the running application and three separate browser profiles with requester, agent, and administrator accounts. Use fictional data. Do not display the private credentials file while screen sharing.

**0:00–0:25 — Context.** Show the public portfolio. Say: “I am Abishek Akash, seeking a trainee IT opportunity in Colombo. I built HelpDeskFlow with AI assistance to practise support workflows and testing. I am learning how the code works.”

**0:25–1:00 — Report.** As requester, create “Training laptop cannot connect to Wi-Fi”. Explain the description, category, and priority. Submit it. Point out that the requester sees only their own tickets.

**1:00–1:40 — Support.** In the agent profile, search for the title, assign it to yourself, and set In Progress. Add a private diagnostic note. Add a public reply asking for a useful detail. Switch to requester and show that the private note is absent.

**1:40–2:15 — Close the loop.** Resolve as the agent with “Corrected the saved network configuration and verified reconnection.” As requester, read the resolution, then reopen with “The connection stopped working again after restarting.” Show the recorded reason in history.

**2:15–2:40 — Administration and boundaries.** Show category controls and status counts. Explain that users cannot change their own role and agents cannot use administration. Never demonstrate privileged credentials publicly.

**2:40–3:00 — Evidence and honesty.** Open test-results.md. Describe the checks actually run and any remaining setup. Say: “AI helped write the implementation. I can demonstrate the workflows and am practising the code and permission rules. GitHub contains the source; a running host is a separate step.”
